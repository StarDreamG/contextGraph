# Agent Workflow

## When Given a New Requirement
1. Determine whether it is an Epic, Feature, Task, Bug, or Design Change.
2. If it is too large, split it into smaller Issues.
3. Ensure each Issue has acceptance criteria.
4. Only implement Ready items.

## When Implementing
1. Read product docs.
2. Read the Issue.
3. Restate the scope.
4. Implement.
5. Test.
6. Prepare PR summary.

## When Finishing
1. Confirm acceptance criteria.
2. Update PR description.
3. Update docs only if stable product knowledge changed.
4. Note follow-up Issues if needed.
